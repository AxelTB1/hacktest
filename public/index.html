How it works

  1. 1. Register a domain Enter the domain you want to review.
  2. 2. Prove control Add a meta tag, verification file, or DNS TXT record. We verify you control the domain.
  3. 3. Run a passive scan We fetch the homepage and analyze headers and known indicators — no active attacks.
  4. 4. Get a report Review a clear summary and actionable security recommendations.

Legal / Responsibility

Website Inspector is built for legal security reviews. You may only use it on systems you own or where you have written permission.

  • No brute force or password testing.
